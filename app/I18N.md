# Интернационализация (i18n) в Buy Point

Этот проект использует `next-intl` для поддержки многоязычности.

## Поддерживаемые языки

- 🇺🇸 **English** (en) 
- 🇷🇺 **Русский** (ru) - язык по умолчанию
- 🇺🇦 **Українська** (uk)

## Структура файлов

```
src/i18n/
├── config.ts              # Основная конфигурация i18n
├── navigation.ts           # Локализованная навигация
├── hooks/
│   └── useTranslations.ts  # Хуки для переводов
├── components/
│   └── LanguageSwitcher.tsx # Компонент смены языка
└── locales/
    ├── en/common.json      # Английские переводы
    ├── ru/common.json      # Русские переводы
    └── uk/common.json      # Украинские переводы
```

## Использование

### В компонентах

```tsx
'use client';

import { useTranslations, useLocale } from 'next-intl';

export function MyComponent() {
  const t = useTranslations();
  const locale = useLocale();

  return (
    <div>
      <h1>{t('common.welcome')}</h1>
      <p>{t('test.description')}</p>
      <p>Текущий язык: {locale}</p>
    </div>
  );
}
```

### Навигация между страницами

```tsx
import { Link } from '@/i18n/navigation';

export function Navigation() {
  return (
    <nav>
      <Link href="/">Главная</Link>
      <Link href="/about">О нас</Link>
      {/* Смена языка */}
      <Link href="/current-page" locale="en">English</Link>
    </nav>
  );
}
```

### Компонент смены языка

```tsx
import { LanguageSwitcher } from '@/i18n/components/LanguageSwitcher';

export function Header() {
  return (
    <header>
      <LanguageSwitcher currentPath="/current-page" />
    </header>
  );
}
```

## Тестовая страница

Для демонстрации функциональности локализации создана тестовая страница:
- `/test-localization` - показывает переключение языков и переводы
- Доступна на всех поддерживаемых языках

## Маршрутизация

- `/` → редирект на `/ru` (язык по умолчанию)
- `/en/page` → английская версия страницы  
- `/ru/page` → русская версия страницы
- `/uk/page` → украинская версия страницы

## Добавление новых переводов

1. Добавьте новые ключи в файлы `locales/{lang}/common.json`
2. Используйте в компонентах через `t('ключ')`
3. Для вложенных объектов: `t('section.key')`

## Добавление нового языка

1. Добавьте код языка в `locales` массив в `config.ts`
2. Создайте папку `locales/{lang}/`  
3. Добавьте файл `common.json` с переводами
4. Обновите компонент `LanguageSwitcher`
